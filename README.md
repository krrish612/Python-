 # Python Programming

A structured, hands-on Python learning repository built from the fundamentals to practical projects.

This repository is organized as a learning path rather than a collection of random scripts. The goal is to learn Python by reading the concept, running the code, practicing it, and then applying it in small projects.

## Learning Path

```text
Python_Tutorial/
├── 01_Basics/
├── 02_Control_Flow/
├── 03_Functions/
├── 04_Data_Structures/
├── 05_OOP/
└── 06_Projects/
```

### 01 — Basics

Start with the Python building blocks:

* What Python is and how it runs
* Printing and basic syntax
* Variables and data types
* Numbers and mathematical operations
* Strings
* User input
* Operators and precedence
* Formatted strings
* Python basics cheat sheet

### 02 — Control Flow

Learn how programs make decisions and repeat work:

* `if`, `elif`, `else`
* Comparison and logical operators
* `for` loops
* `while` loops
* Nested control flow
* Practical exercises

### 03 — Functions

Move from writing repeated code to reusable code:

* Defining functions
* Parameters and arguments
* Return values
* Scope
* Reusable logic
* Function-based exercises

### 04 — Data Structures

Learn how to store and work with collections of data:

* Lists
* Tuples
* Sets
* Dictionaries
* Common operations and patterns
* Practice problems

### 05 — OOP

Build larger programs using object-oriented programming:

* Classes and objects
* Constructors
* Instance and class attributes
* Methods
* Encapsulation
* Inheritance
* Polymorphism

### 06 — Projects

Apply the concepts by building small programs, including:

* Number guessing game
* To-do list
* Calculator
* Weight converter
* Emoji converter
* Car game
* Automation project
* Machine learning project
* Django website project

## How to Use This Repository

Follow the folders in order.

For each topic:

1. Read the theory/notes.
2. Run the example code.
3. Type the code yourself instead of copying it.
4. Complete the exercise before checking a solution.
5. Modify the examples and see what changes.
6. Build something small with the concept.

The repository is designed around active practice, not passive reading.

## Running the Code

Make sure Python 3 is installed.

Check your installation:

```bash
python --version
```

Run a Python file:

```bash
python path/to/file.py
```

Example:

```bash
python Python_Tutorial/01_Basics/01_hello.py
```

## Repository Structure

The main learning material is inside `Python_Tutorial/`.

Each stage contains a mix of:

* `.md` files for explanations and notes
* `.py` files for examples and practice
* Projects that combine multiple concepts

## Learning Philosophy

The progression is intentional:

```text
Syntax
  ↓
Control Flow
  ↓
Functions
  ↓
Data Structures
  ↓
OOP
  ↓
Projects
```

Learn the fundamentals first, then use them repeatedly until they become usable without referring back to notes.

## Progress

This repository is a work in progress. New exercises, examples, and projects can be added as the learning path grows.
